### how to setup
- download the repository
- this tool is built and tested only on Windows 11 and Ubuntu 20.04 with python 3.13
- run `pip install -r requirements.txt`
- depending on what you need 
  - you can write your own code to equip the tools and utilities in here
  - or run `python main.py`
  - or run `python reddit_recon.py`
  - or run `python app.py` for the GUI version

### how to build the GUI
1. first install pyinstaller run `pip install pyinstaller`
2. secondly run `pyinstaller app.spec --clean`
3. you will find the .exe version in the `dist` folder
