### how to setup
- download the repository
- run `pip install -r requirements.txt`
- depending on what you need 
  - you can write your own code to equip the tools and utilities in here
  - or run `python main.py`
  - or run `python reddit_recon.py`
  - or run `python app.py` for app GUI

### how to use
- using the GUI will make it pretty simple you have the option to work with the code and utilize it however you want
